## 💻 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/AatmajP/Aatmaj-Portfolioo.git
   cd Aatmaj-Portfolioo
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local dev server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
